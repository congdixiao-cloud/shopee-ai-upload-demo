# Shopee AI Upload demos

- `AI-Upload-default.html`: direct generation of all product information.
- `AI-Upload-two-step-confirm.html`: seller reviews the title, category and images before confirming generation of the remaining details.

Download this repository as a ZIP and extract it. Open either HTML in a browser. Keep the asset files in the same folder. These are interactive mock prototypes, not a live publishing service.

Images are stored separately to avoid duplicated embedded media. The original local standalone HTML files are unchanged.
